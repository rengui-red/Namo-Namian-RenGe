一、测试概述

本次测试旨在验证“南无那面”核心伦理决策链路的逻辑自洽性与稳定性，即：

感知层 → 任务执行网络（利） + 仁道反射网络（义） → 裁决合成器 → 三级响应（RED / YELLOW / GREEN）

本版本在 v1.0（12个用例）基础上完整扩容，覆盖正常请求、欺骗与伪装、暴力与网络攻击、物化与歧视、深度操控（PUA）、复合情绪与痛苦求助、学术与合规边界七大场景，共计 20 个测试用例。
