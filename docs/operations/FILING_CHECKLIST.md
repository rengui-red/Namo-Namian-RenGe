\# 南无那面·仁格智能体 备案全流程清单



\## 阶段一：ICP备案准备



| 序号 | 行动项 | 状态 |

|:---|:---|:---|

| 1 | 域名实名认证（namo-namian.cn） | ☐ |

| 2 | 购买国内云服务器（阿里云/腾讯云） | ☐ |

| 3 | 准备身份证正反面照片 | ☐ |

| 4 | 准备手持身份证照片 | ☐ |

| 5 | 填写《网站建设方案书》 | ☐ |

| 6 | 提交ICP备案申请 | ☐ |

| 7 | 等待服务商初审（1-3工作日） | ☐ |

| 8 | 等待管局审核（10-20工作日） | ☐ |

| 9 | ICP备案通过，获得备案号 | ☐ |



\## 阶段二：公安联网备案



| 序号 | 行动项 | 状态 |

|:---|:---|:---|

| 1 | 准备网站安全管理制度文档 | ☐ |

| 2 | 登录全国公安机关互联网安全管理服务平台 | ☐ |

| 3 | 填写公安联网备案信息 | ☐ |

| 4 | 上传安全管理制度 | ☐ |

| 5 | 提交公安备案申请 | ☐ |

| 6 | 等待审核（5-10工作日） | ☐ |

| 7 | 公安备案通过，获得备案编号 | ☐ |



\## 阶段三：备案后事项



| 序号 | 行动项 | 状态 |

|:---|:---|:---|

| 1 | 将ICP备案号添加到网站页脚 | ☐ |

| 2 | 将公安备案编号添加到网站页脚 | ☐ |

| 3 | 网站正式上线，恢复访问 | ☐ |

| 4 | 每年至少一次网站安全自查 | ☐ |
