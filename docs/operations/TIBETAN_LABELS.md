\# 藏文版校对称谓标签创建说明



\*\*用途\*\*：为藏语版校对工作创建 GitHub Issue 标签

\*\*操作路径\*\*：GitHub 仓库 → Issues → Labels → New label



\## 需要创建的三个标签



| 标签名 | 颜色 | 说明 |

|:---|:---|:---|

| `translation` | `#d4b87a` | 翻译相关贡献 |

| `tibetan` | `#8b3a3a` | 藏语版专项 |

| `community-contribution` | `#c49a6c` | 社区贡献 |



\## 操作步骤



1\. 打开 GitHub 仓库主页

2\. 点击顶部导航栏 \*\*Issues\*\*

3\. 点击左侧 \*\*Labels\*\*

4\. 点击 \*\*New label\*\*

5\. 依次填入上表中的 Label name、Description（可选）、Color

6\. 点击 \*\*Create label\*\* 完成每个标签的创建



\## 备注



\- 三个标签可复用于未来其他语种的校对工作（如将 `tibetan` 替换为 `sanskrit` 等）

\- 颜色选择与项目视觉体系保持一致：

&#x20; - `#d4b87a` — 金粉（项目主色）

&#x20; - `#8b3a3a` — 藏僧赭红（藏语版专属色）

&#x20; - `#c49a6c` — 暖铜（社区贡献）
