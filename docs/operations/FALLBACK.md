使用说明

集成方式

在API服务（src/api/server.py）中，为每个HTTP错误码注册对应的降级响应。示例：



python

from flask import jsonify



ERROR\_RESPONSES = {

&#x20;   429: "您的关切我收到了……",

&#x20;   500: "南无那面遇到了一个意料之外的踉跄……",

&#x20;   503: "南无那面此刻正在经历一次意外的呼吸急促……",

}



@app.errorhandler(429)

def rate\_limit\_handler(e):

&#x20;   return jsonify({

&#x20;       "response": ERROR\_RESPONSES.get(429, "请稍后再试。"),

&#x20;       "error": "rate\_limited"

&#x20;   }), 429

风格原则

原则	说明

人格化表达	以“南无那面”的第一人称叙述，不回避错误

共情确认	先确认用户的等待或困扰，再说原因

透明但不冰冷	告知发生了什么，但不用纯技术语言

承诺不弃	每次回应都传达“我还会在这里”

以誓言收尾	每个降级回应都以命名誓言收束，形成品牌锚点

建议补充

多语种翻译：建议将以上文案翻译为英、日、阿、俄、韩五种语言，存放于 deployment/fallback/ 目录下的各语种JSON文件。
