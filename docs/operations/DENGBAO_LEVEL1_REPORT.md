一、定级依据

依据《中华人民共和国网络安全法》第二十一条、GB/T 22240-2020《信息安全技术 网络安全等级保护定级指南》及GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》，对本系统进行自主定级。



二、系统描述

项目	内容

系统名称	南无那面·仁格智能体在线服务系统

系统简称	南无那面仁格服务

系统类型	人工智能对话服务（非商业、开源社区运营）

服务范围	提供AI伦理对话、知识库查询、仁商评估工具

用户规模	初期预计日活跃用户 < 1,000人

数据类别	匿名用户标识（openid哈希）、对话内容（默认不存储）

部署方式	云端服务器（Docker Compose编排）

安全责任人	项目核心维护者

三、定级分析

3.1 受侵害的客体

本系统受到破坏时，可能侵害的客体为：



客体类别	是否涉及	说明

公民、法人和其他组织的合法权益	是	若对话数据泄露，可能影响用户隐私

社会秩序、公共利益	否	非关键信息基础设施，不涉及重要公共服务

国家安全	否	不涉及国家秘密、国防、外交等

3.2 受侵害的程度

侵害程度	评估	说明

造成一般损害	是	若服务中断或数据泄露，可能对个别用户造成轻微不便或隐私顾虑

造成严重损害	否	不涉及支付、重要个人信息、关键业务

造成特别严重损害	否	不涉及国家安全、社会秩序、大规模数据泄露

3.3 定级结论

根据定级指南，受侵害客体为“公民、法人和其他组织的合法权益”，受侵害程度为“一般损害”，本系统安全保护等级定为：第一级（自主保护级）。
