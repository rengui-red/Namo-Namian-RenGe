\# 南无那面·仁格智能体 网站建设方案书



\## 一、网站基本情况



| 项目 | 内容 |

|:---|:---|

| \*\*网站名称\*\* | 南无那面开源社区 |

| \*\*网站域名\*\* | namo-namian.cn |

| \*\*主办者性质\*\* | 个人 |

| \*\*网站类型\*\* | 非经营性互联网信息服务 |

| \*\*网站定位\*\* | 开源AI伦理技术文档与公益科普站点 |



\## 二、网站栏目规划



| 栏目名称 | 主要内容 | 功能描述 |

|:---|:---|:---|

| 首页 | 项目介绍、核心理念展示 | 静态图文展示 |

| 文档中心 | 基本法、白皮书、哲学基础、架构设计 | 静态文档展示 |

| 仁商评估 | AI伦理评估标准与测试题库 | 静态文档展示 + 可下载JSON数据 |

| 在线演示 | AI对话演示入口 | 交互式AI对话工具（页面内嵌） |

| 开源社区 | GitHub仓库链接、贡献指南 | 外部链接跳转 |

| 法律声明 | 使用条款、隐私政策、免责声明 | 静态文档展示 |



\## 三、网站内容来源



\- \*\*原创内容\*\*：项目团队原创的技术文档、哲学论述、架构设计、知识库数据。

\- \*\*开源内容\*\*：基于CC BY-SA 4.0许可的公开文档与数据。

\- \*\*不涉及\*\*：新闻采集、用户投稿、爬虫抓取、第三方转载。



\## 四、信息安全保障措施



| 保障项 | 措施说明 |

|:---|:---|

| 内容审核 | 网站内容由项目核心维护者编辑发布，不开放用户直接发布功能 |

| AI对话安全 | 内置“仁盾”安全体系：红线实时拦截、隐性攻击检测、一票否决机制 |

| 数据保护 | 对话默认不存储；不收集用户个人信息；日志无害化记录 |

| 投诉机制 | 在网站明示联系邮箱与举报渠道 |

| 应急响应 | 发现违规内容后24小时内处理并响应 |
