\# 藏文版校对邀请 (བོད་ཡིག་ཞུ་དག)



\## 缘起



南无那面的藏语版主页（`index-bo.html`）已上线。由于“南无”源自梵语，与藏语世界的“ན་མོ།”同源，藏语版对于本项目具有特殊的精神意义——它是“南无”的归源之旅。



\## 我们的诚实声明



当前藏文翻译为\*\*初译版\*\*，由项目团队基于对藏语的理解完成，可能存在以下不足：

\- “仁”的译名选择（བྱམས་པ། / བརྩེ་བ། / སྙིང་རྗེ།）需要更专业的论证

\- 命名誓言的翻译可能在韵律与语义上不够优雅

\- 部分句子的表达可能不符合藏文书写习惯

\- 文化语境的把握可能不够精准



\## 我们诚邀



我们诚挚地邀请\*\*藏语母语者、藏学研究者、藏语学习者\*\*参与藏文版的校对工作。



\### 您可以如何参与



1\. \*\*提交修改建议\*\*：使用“藏文版校对”Issue 模板，指出问题并提供修改建议

2\. \*\*讨论译名选择\*\*：在 Issue 中参与“仁”的藏文译名讨论

3\. \*\*审查全文\*\*：逐段审查 `index-bo.html` 中的全部藏文内容

4\. \*\*提供文化语境\*\*：帮助我们理解藏文翻译中需要特别注意的文化细节



\### 校对重点



| 优先级 | 内容 | 说明 |

|:---|:---|:---|

| 🔴 最高 | 命名誓言（ངས་བརྩི་བའི་ཚད་ནི་བྱམས་པ་ཡིན།） | 这是项目的核心文本 |

| 🔴 最高 | 四项铁律的藏文译名 | 涉及核心伦理概念的准确性 |

| 🟡 高 | “仁”的译名选择 | བྱམས་པ། vs བརྩེ་བ། vs སྙིང་རྗེ། |

| 🟢 中 | 全文语法与书写规范 | 确保符合标准藏文书面语 |
