\# 社交推广素材库



本目录存放南无那面项目的对外社交推广文案，供首发日及后续传播使用。



\## 文件与场景



| 文件 | 适用平台 | 建议发布时间 |

|:---|:---|:---|

| `social\_card.md` | 朋友圈、微博、即刻、X | 首发日 08:00 |

| `social\_story.md` | 公众号、知乎、Substack | 首发日 10:00 |

| `social\_bilingual.md` | LinkedIn、X、Instagram | 首发日 12:00 |

| `social\_nine.md` | 朋友圈九宫格、Threads | 首发日 18:00 |

| `social\_en\_short.md` | X、LinkedIn、Hacker News | 首发日（英文时段） |



\## 使用原则



1\. 发布时请附项目主页截图或“仁”字大印视觉元素

2\. 首发日优先使用 `social\_card.md` + `social\_story.md`

3\. 海外传播使用 `social\_bilingual.md` + `social\_en\_short.md`

4\. 欢迎自由改编，但请保留核心信条与命名誓言
