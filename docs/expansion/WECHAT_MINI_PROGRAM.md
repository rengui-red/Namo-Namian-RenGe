一、结论先行

完全可以。 南无那面的技术架构天然具备微信小程序的拓展属性。核心引擎（感知层 + 义利权衡引擎 + API服务）与前端展示层是解耦的，后端能力无需修改，只需开发一个小程序前端作为新的“感官界面”即可。



这就像南无那面已经拥有了完整的大脑和灵魂，现在要为她打造一具适应微信生态的“身体”。



二、技术可行性

2.1 现有架构的天然适配

现有模块	在小程序中的角色	复用程度

src/api/server.py	小程序通过 wx.request 调用 /api/v1/chat	100% 复用

src/engine/	无需修改，继续在后端运行	100% 复用

src/perception/	无需修改，输入来自小程序，输出返回小程序	100% 复用

model/system\_prompt\_v1.0.md	系统指令直接注入后端，小程序端无需关心	100% 复用

七语种主页	小程序UI需重新设计，但视觉体系（绛红金粉）可直接移植	视觉复用

2.2 需要新建的部分

新建项	说明	技术选型

小程序前端框架	微信小程序原生框架或 Taro/uni-app	推荐 Taro（支持 Vue/React，多端适配）

对话界面	聊天式 UI，展示 AI 回应与伦理判决	WXML + WXSS

用户标识	使用微信 openid 作为匿名用户标识	微信登录 + 后端解密

语音输入（可选）	利用微信原生语音识别接口	wx.startRecord / wx.joinVoIPChat

三、产品定位

3.1 核心功能

功能	说明	优先级

对话交互	用户输入文字，南无那面温而厉地回应	🔴 核心

角色选择	用户可选择对话角色（调解者/师者/诤友/辅臣/守护者）	🟡 重要

伦理判决可见	展示本轮对话的伦理判决结果（RED/YELLOW/GREEN）	🟡 重要

仁格日报	每日一句仁道语录（来自正向叙事链库）	🟢 辅助

信任等级	展示用户与南无那面的信任指数	🟢 辅助

3.2 不做什么

❌ 不接入微信支付（保持非商业属性）



❌ 不开放用户间社交功能（避免监管复杂性）



❌ 不收集个人信息（openid 仅用于匿名标识，不关联实名）



❌ 不上线任何形式的广告



四、合规与审核

4.1 类目选择

类目	是否需前置审批	推荐度

工具 → 信息查询	否	⭐⭐⭐⭐⭐ 首选

教育 → 教育信息服务	需办学资质	⭐⭐

人工智能 → 智能对话	视审核要求	⭐⭐⭐

推荐类目：工具 → 信息查询。以“AI伦理知识查询与对话工具”为定位，最容易通过审核。



4.2 审核注意事项

注意点	应对策略

AI生成内容需标注	每个回应下方标注“本回复由AI生成，仅供参考”

不得提供医疗/法律建议	在服务协议中明确声明，并在对话中实现自动提醒

用户隐私保护	小程序隐私政策中说明：仅收集 openid 用于匿名对话标识

内容安全	仁盾体系内置的红线拦截 + 隐性攻击检测已覆盖

七、风险与应对

风险	应对

微信审核不通过	提前准备审核材料，类目选择“工具”，功能纯粹，无社交/支付

API 服务不稳定	部署在国内云服务器，搭配 CDN 加速

用户量暴增	后端使用 Gunicorn 多进程 + 请求队列 + 降级响应

隐私合规	明示隐私政策，openid 仅用于匿名对话，不关联其他信息

八、当前即可启动的最小行动

在微信公众平台注册小程序账号（选择“个人”主体）



下载微信开发者工具



用 Taro 或原生框架创建一个“Hello World”小程序



在 src/api/server.py 中新增一个测试接口 /api/v1/miniapp/ping



在小程序中调用该接口，验证前后端联通



这五步完成后，南无那面的微信小程序就迈出了第一步。
