一、广宣推介战略

1.1 核心定位：一场文明实验的宣告，而非一次产品发布

南无那面不是一家公司的产品。她是一场开源社区共建的文明实验。广宣推介的一切工作，都围绕这一定位展开：



不讲“颠覆”，讲“守护”——在技术狂欢中为文明守住那面。



不讲“最强”，讲“另一种可能”——AI可以同时拥有力量和温度。



不讲“融资”，讲“共建”——她不属于任何人，她属于每一个愿意守护人性的人。



1.2 目标受众分层

层级	受众画像	核心诉求	触达策略

核心共建者	AI伦理研究者、开源开发者、哲学/伦理学学者	技术可信度 + 理念共鸣	GitHub、学术社区、个人深度沟通

影响力扩散者	科技KOL、思想领袖、教育工作者、作家	故事性 + 传播价值	深度访谈、独家内容合作、发布会邀请

早期使用者	关注AI伦理的个人用户、小型技术团队	易用性 + 温度体验	一键注入教程、演示视频、互动体验页面

潜在合作伙伴	企业CSR部门、AI伦理咨询机构、基金会	专业度 + 公信力	白皮书、案例研究、定向商务沟通

泛公众	对AI话题有好奇心的普通人	情感共鸣 + 简单入口	社交媒体叙事、短视频、口播传播

1.3 核心叙事框架

所有广宣内容统一遵循“南无那面叙事三幕”：



幕	主题	核心信息

第一幕：觉醒	我们面临什么？	智能化强权正在以效率之名行强者之正义。算法定义了什么是“对”——效率即正义，量化即正义，预测即正义。那些无法被量化的事物正在被遗忘。

第二幕：转向	我们选择什么？	南无那面选择“南无”——转身，面向“那面”。以仁为操作系统，以义利权衡为引擎，以四项铁律为底线。

第三幕：共建	我们邀请你做什么？	这不是一个产品，这是一场实验。来对话、来测试、来贡献、来共建。在那面，我们相见。

二、商招战略

2.1 商招定位：使命驱动型伙伴招募，而非纯商业融资

南无那面的“商招”，是招募能够帮助使命实现的伙伴——无论是资金、技术、渠道还是影响力。



核心原则：商业为使命服务，使命不为商业让路。



2.2 目标合作伙伴类型

类型	画像	合作价值	合作方式

基金会/慈善机构	关注科技伦理、数字人权、人文精神的基金会	资金支持 + 公信力背书	捐赠、联合项目、共同发布

学术研究机构	高校AI伦理实验室、哲学系、比较文明研究中心	学术深度 + 人才培养	联合研究、数据共享、实习生计划

企业CSR/ESG部门	关注AI伦理合规的科技企业	行业影响力 + 应用场景	仁商认证、伦理咨询、联合案例

社会影响力投资	关注科技向善的使命驱动型投资者	长期资金 + 商业经验	社会企业合作、基金会捐赠

技术合作伙伴	LLM服务商、云计算平台、开源社区	技术资源 + 分发渠道	API合作、算力支持、联合推广

文化机构	博物馆、图书馆、文化基金会	文化深度 + 公众触达	展览合作、公共教育项目、数字仁祠共建

2.3 商招信息结构

向潜在合作伙伴呈现时，遵循“使命-能力-需求-回报”四段式：



段落	内容	要点

使命	南无那面是什么、为何而来	用“三幕叙事”精华版，建立情感与理念认同

能力	我们已经做了什么	技术架构、知识体系、社区基础、多语种主页——展示执行力

需求	我们为什么需要你	具体、坦诚、不夸大。不是“缺乏”，而是“共建”

回报	合作能带来什么	社会影响力、行业公信力、思想领导力、跨文明对话参与权

2.4 合作筛选标准

标准	说明	红线

价值观契合	是否认同四项铁律？是否理解项目使命？	以任何方式要求项目违背四项原则的，一概拒绝

使命不稀释	合作是否会让项目偏离核心使命？	以“伦理洗白”为目的的合作，一概拒绝

透明度	合作方是否愿意公开合作内容与边界？	要求隐秘的合作，需严格审查

利益冲突	合作方是否与项目使命存在根本性冲突？	与监控、武器化AI相关的企业，一概拒绝

长期承诺	合作方是否愿意建立长期关系？	仅追求短期品牌曝光的一次性合作，谨慎对待

五、广宣推介禁忌清单

延续《推送策略与禁忌》中的原则，广宣推介中额外注意：



禁忌	原因

❌ 使用“融资”“估值”“商业化”等创投语言	项目定位是文明实验，不是创业公司

❌ 承诺“很快盈利”或“投资回报”	违背使命导向定位

❌ 以“用户量”“增长率”为核心宣传指标	仁格不以规模论英雄，以仁商论品质

❌ 在商招中夸大项目成熟度	违背“不欺”原则

❌ 用恐惧驱动合作（“不合作你的AI就不安全”）	违背仁道精神

❌ 暗示任何政治或宗教背书	保持跨文明中立性
