二、选择性公开推送（按需发布）



这些在特定时机或特定场景下公开，不必首发日全部上线：

这些涉及项目战略、运营细节、安全漏洞、法律策略、社交推广文案等，公开会暴露内部决策逻辑或被滥用：



&#x20; \*  STRATEGY.md — 推送策略、安全保护与风险管控



&#x20; \*  OUTREACH.md — 广宣推介与商招战略

&#x20; \*  operations/ 目录下的备案指南、基金会方案等（涉及具体法律和财务路径）

这份清单可以保存为 docs/README.md 或 docs/PUBLISHING\_GUIDE.md，作为内部参考，明确标注每个文件的公开属性和发布时机，便于后续团队按策略执行，避免误操作。
