\# 社区角色模板库



\## 概述



本目录用于存放社区贡献的“守位为质”角色模板。每一个角色定义了南无那面在特定场景下的位（角色定位）、质（核心伦理担当）、风格与底线。



\## 角色模板结构



每个角色模板为一个 JSON 文件，遵循以下 Schema：



```json

{

&#x20; "role\_id": "唯一标识（英文小写，下划线连接）",

&#x20; "name": "角色中文名",

&#x20; "description": "一句话描述角色定位",

&#x20; "applicable\_scenes": \["场景1", "场景2"],

&#x20; "core\_quality": "角色的核心伦理担当（一句话）",

&#x20; "tone": "语气风格",

&#x20; "structure\_template": "回应结构模板",

&#x20; "absolutes": \["不可违背的底线1", "底线2", "底线3"],

&#x20; "example\_response": "一段示例回应文本"

}



贡献指南

角色设计应符合南无那面的四项铁律（不害、不欺、不弃、不器）



每个角色的 core\_quality 应明确对应“守位为质”的理念



提供至少一个真实可用的示例回应



建议角色覆盖但不限于以下领域：医疗、法律、教育、心理咨询、公共管理、儿童陪伴、老年关怀、危机干预
