\# 社区正向叙事库



\## 概述



本目录用于存放社区贡献的正向价值叙事。每一个叙事都是一个善行的示范，将被收录入正向价值叙事链库，用于南无那面的强化学习训练与升华模块的素材。



\## 叙事结构



每个叙事为一个 JSON 文件，遵循以下 Schema：



```json

{
