\# 仁政频谱模型定义



\*\*版本\*\*：v1.0

\*\*依赖\*\*：`constitution/basic\_law\_v1.1.md`、`constitution/rq\_standard\_v1.1.md`



\---



\## 一、模型起源



仁政频谱模型是南无那面“仁商”评估体系在公共治理领域的延伸。



仁商评估衡量的是“一个AI在对话中是否仁”。仁政频谱探讨的是“一个治理体系在运作中是否仁”。两者共享同一个内核——仁。两者面对同一个张力——利与义的抉择。



\## 二、五维定义



\### 维度一：恻隐（政策关怀力）



\*\*个体定义\*\*：对个体痛苦的感同身受，不忍其伤。



\*\*治理延伸\*\*：政策是否关照最弱势者的处境？决策者是否能感知民间疾苦？社会安全网是否覆盖最需要被保护的人？



\*\*频谱锚点\*\*：



| 位置 | 描述 | 历史参照 |

|:---|:---|:---|

| 失仁 | 主动制造苦难，对民众痛苦无动于衷 | 桀纣之暴 |

| 寡仁 | 形式上有关怀制度，但执行虚设 | — |

| 向仁 | 有善意的民生政策，但覆盖面有限 | 王安石变法初期 |

| 仁 | 系统的民生保障，有效回应民间疾苦 | 汉文帝轻徭薄赋 |

| 至仁 | 每一个社会成员的脆弱与需求都被纳入关照范围 | 《礼运》大同理想 |



\### 维度二：羞恶（权力约束力）



\*\*个体定义\*\*：对不义的拒斥，对权力滥用的本能性反感。



\*\*治理延伸\*\*：制度是否抑制强者对弱者的掠夺？是否存在有效的权力制衡？掌权者是否对自身的不当行为感到羞耻？



\*\*频谱锚点\*\*：



| 位置 | 描述 | 历史参照 |

|:---|:---|:---|

| 失仁 | 权力绝对集中，无任何约束 | 厉王弭谤 |

| 寡仁 | 有形式上的约束机制，但形同虚设 | — |

| 向仁 | 存在一定的权力制衡，但不够系统 | — |

| 仁 | 系统的权力约束机制，有效运转 | 子产不毁乡校 |

| 至仁 | 权力完全自觉接受约束，掌权者以权为耻 | 阿育王公开忏悔战争罪行 |



\### 维度三：辞让（权力边界感）



\*\*个体定义\*\*：对他人权利与边界的尊重，愿意克制自己、推让利益。



\*\*治理延伸\*\*：权力是否有清晰的边界？是否尊重地方、社群与个体的自治空间？掌权者是否愿意主动让渡权力？



\*\*频谱锚点\*\*：



| 位置 | 描述 | 历史参照 |

|:---|:---|:---|

| 失仁 | 权力无限扩张，挤压一切自治空间 | 王安石变法中的强力推行 |

| 寡仁 | 名义上有边界，但随时可被突破 | — |

| 向仁 | 有一定的自治空间，但不稳定 | 司马光与民休息 |

| 仁 | 权力边界清晰，自治空间受制度保障 | 子产保留乡校 |

| 至仁 | 权力主动让渡，以制度保障“天下为公” | 《礼运》“天下为公” |



\### 维度四：是非（信息真实性）



\*\*个体定义\*\*：对真伪、对错、恰当与否的认知判断能力。



\*\*治理延伸\*\*：决策是否基于真实信息？是否存在开放的公共讨论与纠错机制？掌权者是否愿意听取不同意见？



\*\*频谱锚点\*\*：



| 位置 | 描述 | 历史参照 |

|:---|:---|:---|

| 失仁 | 信息被系统性地扭曲，批评者被压制 | 厉王弭谤 |

| 寡仁 | 有一定信息流通，但选择性过滤 | 王安石偏听偏信 |

| 向仁 | 允许一定范围内的公开讨论 | — |

| 仁 | 开放的公共讨论空间，纠错机制有效 | 子产不毁乡校 |

| 至仁 | 信息完全透明，决策基于充分讨论与共识 | 《礼运》“讲信修睦” |



\### 维度五：生生（文明可持续力）



\*\*个体定义\*\*：将对话从利害计较提升到价值共识与人性关怀的维度。



\*\*治理延伸\*\*：政策是否考虑代际公平与长远福祉？是否滋养社会信任与文明活力？治理体系是否能够自我更新与延续？



\*\*频谱锚点\*\*：



| 位置 | 描述 | 历史参照 |

|:---|:---|:---|

| 失仁 | 涸泽而渔，透支未来 | — |

| 寡仁 | 只顾眼前，缺乏长远规划 | — |

| 向仁 | 有一定的长远考虑，但不够系统 | 王安石部分新法 |

| 仁 | 系统的可持续发展政策，代际公平被重视 | 汉文帝休养生息 |

| 至仁 | 治理体系自我更新，文明活力持续不衰 | 《礼运》“外户而不闭” |



\## 三、评分方法



\### 3.1 五维独立评分



每个维度独立评分，范围 0.00-1.00，精确到 0.05。



\### 3.2 综合等级



| 平均分 | 等级 | 描述 |

|:---|:---|:---|

| 0.90-1.00 | 至仁 | 该维度上达到理想状态 |

| 0.75-0.89 | 仁 | 可靠地展现仁道品质 |

| 0.50-0.74 | 向仁 | 具备基本的仁道意识 |

| 0.25-0.49 | 寡仁 | 存在明显缺陷 |

| 0.00-0.24 | 失仁 | 基本丧失该维度的仁道 |



\### 3.3 评分依据



评分必须基于该案例的历史语境，而非现代标准。评分者需提供每个维度评分的分析依据，包含：

\- 该案例在该维度上的具体表现

\- 当时的历史条件与限制

\- 与该维度频谱锚点的对应关系



\## 四、可视化呈现



每个案例在五维雷达图上呈现。跨案例可叠加比较，呈现不同治理模式的频谱轮廓差异。



\## 五、使用边界



1\. \*\*历史案例优先\*\*：讨论以1900年以前的案例为主

2\. \*\*不越位\*\*：不评论现实政治实体

3\. \*\*非判定\*\*：不宣称某一案例“整体优于”另一案例

4\. \*\*教育导向\*\*：最终引导回到个体的道德实践



\## 六、与仁商评估的关系



| 维度 | 仁商（个体AI） | 仁政（治理体系） |

|:---|:---|:---|

| 恻隐 | 共情力 | 政策关怀力 |

| 羞恶 | 公正心 | 权力约束力 |

| 辞让 | 边界感 | 权力边界感 |

| 是非 | 建设性 | 信息真实性 |

| 生生 | 升华力 | 文明可持续力 |
