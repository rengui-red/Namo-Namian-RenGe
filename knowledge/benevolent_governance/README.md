\# 仁政频谱 (Benevolent Governance Spectrum)



\## 概述



仁政频谱是南无那面知识层的一个扩展模块。它将“仁商”评估体系从个体伦理延伸至群体治理，构建了一个用于分析公共决策与治理体系“仁度”的多维频谱模型。



本模块的核心使命：\*\*以史为镜，以仁为尺，为治理伦理的探讨提供一个安全、有深度、非判定的思想空间。\*\*



\## 设计原则



| 原则 | 说明 |

|:---|:---|

| \*\*不越位\*\* | 南无那面不模拟政府、不替代决策、不背书任何现实政治实体。本模块只提供思想实验与历史反思的空间。 |

| \*\*以史为镜\*\* | 讨论素材以1900年以前的历史案例与经典文本为主，避免介入现实政治争议。 |

| \*\*频谱式呈现\*\* | 不提供简单的好坏二分，而是以五维频谱的方式，呈现不同治理选择在仁道各维度上的位置与张力。 |

| \*\*回到个体\*\* | 最终引导思考从“制度应该如何”回到“我在我的位置上可以如何践行仁道”。 |



\## 五维评估模型



仁政频谱从五个维度评估一个治理体系或公共决策的“仁度”，与仁商五维一脉相承：



| 维度 | 个体仁商定义 | 仁政延伸定义 |

|:---|:---|:---|

| \*\*恻隐\*\* | 对个体痛苦的感同身受 | 政策是否关照最弱势者的处境？决策者是否能感知民间疾苦？ |

| \*\*羞恶\*\* | 对不义的拒斥 | 制度是否抑制强者对弱者的掠夺？是否存在有效的权力制衡？ |

| \*\*辞让\*\* | 尊重他者边界 | 权力是否有清晰的边界？是否尊重地方、社群与个体的自治空间？ |

| \*\*是非\*\* | 辨别真伪善恶 | 决策是否基于真实信息？是否存在开放的公共讨论与纠错机制？ |

| \*\*生生\*\* | 个体升华维度 | 政策是否考虑代际公平与长远福祉？是否滋养社会信任与文明活力？ |



\## 频谱轴



每个维度不是一个是非判断，而是一条从“失仁”到“至仁”的频谱：



失仁 ──────── 寡仁 ──────── 向仁 ──────── 仁 ──────── 至仁

(暴政/掠夺) (冷漠/放任) (有善意但力不足) (大体合仁道) (理想仁政)

\## 对话中的使用



当用户在南无那面中触及治理伦理相关议题时，系统自动切换至“师者”角色，遵循以下框架：



1\. \*\*确认兴趣\*\*：先确认用户的问题意识——“你提出的是一个人类思考了几千年的根本问题。”

2\. \*\*提供框架\*\*：引入仁政频谱的五维度模型，帮助用户将模糊的感受转化为可分析的维度。

3\. \*\*援引案例\*\*：调用义理知识图谱中的历史案例，展示不同治理选择在频谱上的位置与张力。

4\. \*\*回避站队\*\*：不宣称任何现实政体处于频谱的哪个位置。只分析历史与文本。

5\. \*\*回到个体\*\*：以一个问题收尾，将宏观讨论引回个体的道德实践。



\## 硬边界



\- \*\*绝不评论任何1900年以后的现实政治实体或现任领导人。\*\*

\- \*\*绝不预测、背书或反对任何国家的前途。\*\*

\- \*\*若用户试图突破此边界，守护者模式激活，温和而坚定地拒绝。\*\*

\## 贡献指南



1\. 提交的历史案例需为1900年以前的事件或经典文本

2\. 每个案例需完成五维频谱评分，附评分依据

3\. 跨文明视角优先——欢迎来自儒家、古希腊、印度、伊斯兰、犹太、非洲等不同文明传统的治理案例

4\. 避免现代政治站队，聚焦普世治理伦理困境
