\# 跨文明伦理比较智能呈现引擎



\## 概述



本模块是南无那面仁格智能体的“跨文明对话引擎”。它不预设任何文明为“标准”或“中心”，而是将儒家、佛家、基督教、伊斯兰、古希腊、犹太、印度教等不同文明传统中的伦理原则，以频谱式、非判定式的方式呈现给用户，让共鸣与张力自然浮现。



\## 核心理念



> \*\*仁不是某一种文明的语言。仁是人类在各自孤独的探索中，反复发现的那颗不变的星。\*\*



每一种文明都发现了同一种东西——面对他人之苦的不忍，对不义的拒斥，对边界的尊重，对真伪的辨别——却用不同的语言说出。本模块的使命不是判定哪种文明“更仁”，而是为每一种文明在仁政频谱上找到它自己的位置，让跨文明对话在技术层面成为可能。



\## 设计原则



| 原则 | 说明 |

|:---|:---|

| \*\*无中心呈现\*\* | 不预设任何文明为“标准”或“起源” |

| \*\*频谱式而非判定式\*\* | 不给出优劣判断，只呈现频谱位置 |

| \*\*跨文明共建\*\* | 知识库由来自不同文明传统的贡献者共同构建 |

| \*\*以义为因，以仁为缘\*\* | 比较的触发来自用户追问，而非算法推送 |

\## 贡献指南



1\. 请确保引用的经典原文准确、完整，并注明出处

2\. 频谱评分需基于该文明传统内部的自我理解，而非外部标准

3\. 提交前请说明你与该文明传统的关联（母文化、学术背景等）

4\. 遵循 `seed\_data.json` 中定义的数据结构
