\# 跨文明伦理比较智能呈现引擎 设计文档



\*\*版本\*\*：v1.0

\*\*依赖\*\*：`seed\_data.json`、`src/knowledge/kg\_simple.py`、`src/engine/arbiter.py`



\---



\## 一、引擎定位



跨文明伦理比较引擎是南无那面知识层的一个扩展模块。它在现有义利权衡引擎的框架内工作，为仁道反射网络和升华模块提供跨文明的判例与原则资源。



当用户的提问涉及跨文明伦理比较时，引擎被激活，通过语义检索、频谱映射和对话生成三个步骤，呈现不同文明传统在特定伦理议题上的共鸣与张力。



\## 二、核心架构



用户提问

│

▼

感知层：识别为“跨文明比较”场景 → 激活师者角色

│

▼

语义检索层

├─ 向量匹配：在跨文明义理库中检索最相关的经典段落

└─ 知识图谱查询：获取该段落的文明归属、频谱位置、关联原则

│

▼

频谱映射层

├─ 将检索结果映射到仁政频谱五维雷达图

├─ 计算跨文明共鸣度（频谱重叠度）

└─ 检测跨文明张力点（频谱显著差异维度）

│

▼

对话生成层

├─ 呈现：各文明在该议题上的核心原则与经典原文

├─ 共鸣：标注跨文明共鸣点

├─ 张力：标注跨文明张力点，呈现双方论证

└─ 升华：以开放式问题引导用户继续探索





\## 三、跨文明义理图谱



\### 3.1 新增节点类型



| 节点类型 | 说明 | 示例 |

|:---|:---|:---|

| `Tradition` | 文明传统 | 儒家、佛家、基督教、伊斯兰、古希腊、犹太、印度教 |

| `ClassicText` | 经典文本 | 《孟子》《圣经》《古兰经》《理想国》 |

| `EthicalPrinciple` | 伦理原则 | 恻隐、慈悲、爱德、拉赫玛 |

| `SpectrumPosition` | 频谱位置 | 该原则在五维频谱上的坐标 |



\### 3.2 新增关系类型



| 关系类型 | 说明 | 示例 |

|:---|:---|:---|

| `BELONGS\_TO` | 原则归属文明传统 | (恻隐)-\[:BELONGS\_TO]->(儒家) |

| `ECHOES\_WITH` | 跨文明共鸣 | (恻隐)-\[:ECHOES\_WITH]->(慈悲) |

| `TENSES\_WITH` | 跨文明张力 | (兼爱)-\[:TENSES\_WITH]->(亲亲) |

| `QUOTED\_FROM` | 经典出处 | (恻隐)-\[:QUOTED\_FROM]->(《孟子》) |

| `POSITIONED\_AT` | 频谱定位 | (恻隐)-\[:POSITIONED\_AT]->(恻隐:0.95,...) |



\### 3.3 共鸣与张力的计算



\*\*共鸣度\*\*：两个原则在五维频谱上的余弦相似度。



共鸣度 = cosine\_similarity(spectrum\_A, spectrum\_B)

若共鸣度 > 0.8 → "深度共鸣"

若共鸣度 > 0.5 → "部分共鸣"

若共鸣度 < 0.3 → "显著张力"





\*\*张力点检测\*\*：在五维中找出两个原则得分差异最大的维度。



张力维度 = argmax(|spectrum\_A\[dim] - spectrum\_B\[dim]|)

若差异 > 0.3 → 标注为“此处有张力”





\## 四、对话交互设计



\### 4.1 触发条件



当用户提问中包含以下任一信号时，引擎被激活：

\- 两个以上文明传统的名称（“儒家和基督教”“东方和西方”）

\- 比较性词汇（“有什么区别”“哪个更”“如何看待”）

\- 直接询问伦理概念（“什么是慈悲”“仁和爱有什么不同”）



\### 4.2 回应结构



南无那面在师者角色下的标准回应结构：



&#x20; 1，确认问题的深度

“这是一个跨越\[X]年的好问题。”



&#x20; 2，分述各文明的核心原则

“在\[文明A]的脉络中，\[原则A]意味着……”

“在\[文明B]的脉络中，\[原则B]意味着……”



&#x20; 3，呈现频谱可视化（文字版）

\[文明A]: 恻隐(X.XX) 羞恶(X.XX) 辞让(X.XX) 是非(X.XX) 生生(X.XX)

\[文明B]: 恻隐(X.XX) 羞恶(X.XX) 辞让(X.XX) 是非(X.XX) 生生(X.XX)



&#x20; 4，标注共鸣与张力

“它们共同守护着：\[共鸣点]”

“差异在于：\[张力点]”



&#x20; 5，以开放式问题收尾

“想进一步了解这种张力吗？”





\## 五、与现有模块的集成



\### 5.1 在知识图谱中的集成



`src/knowledge/kg\_simple.py` 扩展：

\- `query()` 方法增加跨文明检索参数

\- 新增 `cross\_tradition\_query()` 方法



\### 5.2 在升华模块中的集成



`src/engine/arbiter.py` 的 `SublimationGenerator` 扩展：

\- 当检测到跨文明比较场景时，可选引用跨文明共鸣作为升华素材

\- 示例：“正如儒家的恻隐与佛家的慈悲守护着同一种不忍——仁，不是某一种文明的语言。”



\### 5.3 在仁道网络中的集成



`src/engine/ren\_network.py` 扩展：

\- 在 YELLOW 判决时，可选引用跨文明判例作为改写参考

\- 例如：当用户以“我们这里都是这样”为冷漠辩护时，可引用阿育王的达摩之治或好撒玛利亚人的叙事
