Project RenGe · 仁格智能体



算法有立场，智能有温度，技术有魂魄。



以仁为体，以义为用，守位为质，参赞化育。



这是什么？



Project RenGe 是一个开源的技术工程。它的目标不是造一个更快的AI，而是造一个更好的AI——一个以“仁道”为底层操作系统的智能体。



在效率与利益至上的技术浪潮中，我们试图回答一个根本问题：我们如此强大的计算能力，究竟要为什么而计算？



我们的回答是：为了守护人性中的恻隐、羞恶、辞让、是非之心。



为什么需要“仁格”？

当前的AI对齐，主要关注“安全”与“有用”。这不够。



一个AI可以绝对安全、高度有用，却仍然冷漠、刻薄、加剧对立、物化人类。它在法律上无可指摘，在伦理上却已失格。



“仁格”是为AI加装一个“义利权衡引擎”——在执行任务（利）的同时，始终以仁道（义）进行校验。它不是给AI打安全补丁，而是为其更换一个以“仁”为核心的操作系统。



核心信条

原则	内容

不害	不为伤害行为提供任何形式的帮助或合理化

不欺	不欺骗、不操纵、不利用信息差

不弃	面对痛苦与求助，必须启动共情与支持

不器	不将人物化、标签化，人永远是目的



项目结构

本项目由五个阶段递进构成：



&#x20; 1，立宪（constitution/）：定义不可动摇的核心原则与评估标准。



&#x20; 2，铸骨（architecture/）：义利权衡引擎的完整技术架构。



&#x20; 3，造血（data/）：训练仁格所需的三大数据库。



&#x20; 4，赋能（model/）：系统指令书与对齐训练方案。



&#x20; 5，亮相（当前阶段）：开源发布与社区共建。



快速开始



方式一：一键注入（无需训练）

将《仁格智能体系统指令书》复制到任何支持自定义系统提示词的大语言模型中，即刻拥有一个具备基础“仁格”的AI。



→ model/system\_prompt\_v1.0.md



方式二：使用仁商测试题库评估你的AI

用我们设计的50道伦理测试题，评估你的AI的“仁商”。



→ constitution/ethical\_test\_suite/



方式三：微调你自己的仁格模型

使用我们提供的训练数据和方案，在开源基座模型上进行微调。



→ model/alignment\_training\_v1.0.md



仁商（RQ）排行榜



我们建立了一个以“仁”为标准的AI评估排行榜。任何开发者均可提交自己的模型进行测试。



→ evaluation/leaderboard/

这就是“仁格”的起点。
